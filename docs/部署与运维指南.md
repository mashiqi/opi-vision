# 部署与运维指南

> Orange Pi Zero 3W（Allwinner A733）+ IMX219 视觉推流。SRT 加密公网 → 云端 MediaMTX → WebRTC。
> 最后更新：2026-08-11

## 硬件

- **SoC**：Allwinner A733 — 2×A76 + 6×A55 + 玄铁 E902 RISC-V
- **内存**：LPDDR5（≈51.2 GB/s）
- **摄像头**：IMX219，MIPI CSI-2
- **网络**：WiFi 6，无有线网口
- **操作方式**：仅 SSH，无显示器/音频输出

## 架构

```
imx219 → ISP(3A) → NV12 → [nv12-timestamp] → aw-h264-encoder → H.264 pipe
                                                                    ↓
                            config/audio.opus → ffmpeg(mux, copy) → MPEG-TS
                                                                    ↓
                                              ┌── UDP 127.0.0.1:8891 → 本地 MediaMTX → RTSP/WebRTC
                                              └── SRT/AES  云端:8890 → 云端 MediaMTX → Nginx WHEP → 公网 WebRTC
```

视频编码使用 Cedarc 硬编码，音频由 ffmpeg 直接复制合流（无需重编码）。`tee` muxer 同时输出本地 UDP 和加密 SRT，互不影响。

`nv12-timestamp`（可选）在 NV12 阶段、硬编码之前写入实时时间戳，仅修改 Y 平面（亮度），CPU 开销不可感知。

## 板端部署

### 1. 配置

```bash
cd ~/orangepi-vision
cp config/vision.env.example config/vision.env
```

编辑 `config/vision.env`，填写 SRT 公网五項（全留空则不启用公网转发）：

```bash
VISION_SRT_CLOUD_HOST=你的域名
VISION_SRT_PASSPHRASE=24位AES密码
VISION_SRT_USERNAME=发布用户名
VISION_SRT_PASSWORD=发布密码
VISION_SRT_LATENCY_MS=2000
```

密码和用户名要求 16–32 位字母、数字、`_`、`-`：

```bash
tr -dc 'A-Za-z0-9_-' </dev/urandom | head -c 24; echo
```

### 2. 音频文件

将 48 kHz 双声道 Opus 文件命名为 `audio.opus` 放入 `config/` 目录。

如需自备音频（如 MP3），用 ffmpeg 转换：

```bash
ffmpeg -i 你的文件.mp3 -c:a libopus -b:a 64k -ar 48000 -ac 2 audio.opus
```

`-ar 48000 -ac 2` 确保 48 kHz 双声道，`-b:a 64k` 为推荐码率。

```bash
# 启动（默认带音频）
./vision --start

# 纯视频，无音频
./vision --start --audio off
```

文件缺失或格式不符时自动降级为纯视频推流，不阻塞启动。

### 3. 服务管理

```bash
./vision --start          # 启动（3 秒无输入则 Camera 模式）
./vision --start --size 1920x1080 --fps 15
./vision --start --timestamp on   # 启视频时间戳叠加
./vision --status         # 运行摘要
./vision --log            # 进程详情和日志
./vision --stop           # 停止
./vision --help           # 全部参数
```

### 4. 视频时间戳

通过 `--timestamp on|off` 控制。默认开启。在 NV12 原始帧上、硬编码之前写入当前系统时间（`YYYY-MM-DD HH:MM:SS`），位于最终画面左上角。

**前置步骤**：板端首次使用前编译二进制：

```bash
cd ~/orangepi-vision/src/src-camera && bash build-board-tools.sh
```

**实现**：`bin/nv12-timestamp`（源码 `src/src-camera/nv12-timestamp.c`），纯 C、零外部依赖。标准 VGA 8×16 位图字体，仅修改 Y 平面亮度不影响色度。支持编码器旋转 `--rotate 0|90|180|270`。

**关闭**：`./vision --start --timestamp off`。默认 `on`。在 `config/vision.env` 中设 `VISION_TIMESTAMP_ENABLED=off` 可持续关闭。

## 云端部署

### MediaMTX

从 `config/mediamtx.yml.ToBeUploadToOnlineServer.example` 复制配置到云端 `~/mediamtx/mediamtx.yml`，替换占位符。

```yaml
logLevel: info
rtsp: false; rtmp: false; hls: false; moq: false; api: false
srt: true
srtAddress: :8890
webrtc: true
webrtcAddress: 127.0.0.1:8889
webrtcLocalUDPAddress: :8189
webrtcAdditionalHosts: [你的域名]
authMethod: internal
authInternalUsers:
  - user: board_publisher_001
    pass: 发布密码
    permissions: [{action: publish, path: vision}]
  - user: any
    pass:
    permissions: [{action: read, path: vision}]
paths:
  vision:
    srtPublishPassphrase: 24位AES密码
```

systemd 服务：

```ini
# /etc/systemd/system/mediamtx-cloud.service
[Unit]
Description=MediaMTX SRT to WebRTC
After=network-online.target
Wants=network-online.target

[Service]
User=<cloud-user>
WorkingDirectory=/home/<cloud-user>/mediamtx
ExecStart=/home/<cloud-user>/mediamtx/mediamtx /home/<cloud-user>/mediamtx/mediamtx.yml
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now mediamtx-cloud
```

### Nginx

`/vision/` 为播放页，`/vision/whep` 反代本机 MediaMTX：

```nginx
location = /vision/whep {
    proxy_pass http://127.0.0.1:8889/vision/whep;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_request_buffering off;
    proxy_read_timeout 3600;
}

location /vision/ {
    alias /var/www/vision/;
    index index.html;
    try_files $uri $uri/ =404;
}
```

### 防火墙

云安全组和 UFW 仅放行 UDP `8890`（SRT）与 UDP `8189`（WebRTC ICE）：

```bash
sudo ufw allow 8890/udp
sudo ufw allow 8189/udp
```

## 注意事项

- **音频时间戳**：ffmpeg 合成时须使用 `-use_wallclock_as_timestamps 1`（当前已默认）。若改用固定帧率时间戳，isp3a-daemon 在暗光下会自动提高曝光时间、降低实际帧率，导致音视频时间轴错位，表现为音频卡顿。
- **音频文件**：须为 48 kHz 双声道 Opus，命名为 `audio.opus` 放入 `config/`。使用 `--audio off` 可仅推视频流。文件缺失或格式不符时自动降级为纯视频，不阻塞服务。

## 故障排查

- **板端启动失败**：检查 `audio.opus` 是否存在、SRT 五项是否完整、硬编码设备 `/dev/cedar_dev_ve2` 是否可读写。
- **SRT 无法连通**：核对双方五项配置一致，确认云端 UDP 8890 可达。
- **浏览器无画面**：检查 UDP 8189 安全组/UFW、域名 DNS 和 `webrtcAdditionalHosts`。
- **本地视频异常**：`./vision --log` 查看 publisher.log 和 isp3a.log。
